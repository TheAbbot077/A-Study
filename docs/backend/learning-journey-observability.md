# Learning Journey Observability

Operational observability is provided through:

- action receipts;
- journey operations;
- integrity findings;
- release-readiness reports;
- identifier-only business events;
- structured application logs in orchestration services;
- admin filters and read-only inlines;
- management command summaries.

Sensitive content must not be logged or emitted:

- raw teaching responses;
- concept-check answers;
- diagnostic answers;
- private reflections;
- mentor memory;
- authentication data.

Metrics should use bounded labels only: action code, result, status, severity, and source capability. Journey IDs and learner IDs are not metric labels.
