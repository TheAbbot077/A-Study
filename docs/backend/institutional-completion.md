# Institutional Completion

PI-8B.4 adds completion readiness, not certification.

`InstitutionalCompletionService` evaluates required competencies through existing `LearningCompetencyProgress` records. A required competency is satisfied only when progression shows it as demonstrated or reinforced.

The service does not:

- issue certificates;
- create transcripts;
- calculate grades;
- perform registrar workflows;
- replace assessment grading.

## Intervention recommendations

`InstitutionalInterventionService` observes competency progression and may create recommendations when governed progress signals risk, such as:

- repeated review required;
- persistent regression.

Recommendations do not alter mastery decisions. They are operational prompts for institutional support.

## Learning plan evolution

`InstitutionalLearningPlanEvolutionService` projects institutional delivery objectives and required competencies as inputs to existing planning capabilities. Learner adaptation is allowed only inside the institutional authority boundary.
