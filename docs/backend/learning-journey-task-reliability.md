# Learning Journey Task Reliability

Learning journey operations reuse existing task boundaries from self-study and related capabilities.

Important self-study task names:

- `self_study.resolve_curriculum`
- `self_study.create_bridge_plan`
- `self_study.finalize_bridge_plan`
- `self_study.assemble_teaching_preparation`
- `self_study.evaluate_teaching_readiness`
- `self_study.prepare_teaching_turn`
- `self_study.record_teaching_evidence`
- `self_study.advance_teaching_session`

Task payloads use identifiers and avoid raw learner answers, transcripts, mentor memory, or private notes. Operational readiness reports missing task registration as a warning or blocker according to release criteria.
